<objective>
Remove the seven empty-string sentinel assignments from the location, object, and property
attribute providers so that unresolved optional attributes are omitted from the bag.

Purpose: the DSL evaluator's fail-safe semantics treat a MISSING attribute as false for every
operator, but they do not treat a present-but-empty value as missing. Two unresolved
attributes compared against each other therefore satisfy an equality test and produce a
permit — a latent elevation-of-privilege path in a default-deny system. Two providers in the
same package already carry the correct form and the explanatory comment; three do not.

Output: three providers matching the in-repo reference form, and tests that prove absence
rather than pinning the sentinel.

Decisions implemented: D-17 (this is one of the four Medium-cluster items that land).
</objective>
