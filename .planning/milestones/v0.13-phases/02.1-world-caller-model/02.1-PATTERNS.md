## Pattern Assignments

### `internal/world/<caller>.go` (model, opaque value)

**Primary analog:** `internal/access/policy/types/types.go:206-230` — the repo's closest existing
opaque domain value: unexported fields, a constructor that derives dependent state, method
accessors.

```go
// internal/access/policy/types/types.go:206-230 (verbatim)
type Decision struct {
	allowed    bool
	effect     Effect
	reason     string
	policyID   string
	policies   []PolicyMatch
	attributes *AttributeBags
}

// NewDecision creates a Decision with the allowed field set consistently
// based on the effect: Allow and SystemBypass grant access, all others deny.
func NewDecision(effect Effect, reason, policyID string) Decision {
	allowed := effect == EffectAllow || effect == EffectSystemBypass
	return Decision{
		allowed:  allowed,
		effect:   effect,
		reason:   reason,
		policyID: policyID,
	}
}

// IsAllowed returns whether the decision grants access.
func (d Decision) IsAllowed() bool {
	return d.allowed
}
```

**Copy:** value receiver on accessors; constructor derives the dependent field (`allowed` from
`effect`) rather than taking it — the caller type should likewise derive `system bool` from
`SystemCaller()` vs `HumanCaller()`, never accept it as a parameter.

**Method-value gotcha (CLAUDE.md Error Handling):** `Decision.Reason()` is a *method*, and this
repo has been bitten by `oops.With("reason", decision.Reason)` compiling silently. If the caller
type's subject is exposed as a method, every `buildIntent(..., c.Subject(), ...)` site needs the
parens — and `wmodel.IntentParams.Actor` is a free `string` with no validation
(RESEARCH Pitfall 5), so a method value would be caught only by the compiler's `any` boundary,
i.e. possibly not at all. Consider an accessor name that cannot be confused, or a `string`-typed
package-internal field access inside `package world` (the only consumer of the subject is
`package world` itself plus `internal/property` if threaded).

**Secondary analog — the census-provable closed construct** (`internal/world/mutator.go:63-100`):

```go
// internal/world/mutator.go:63-76 (verbatim)
// WriteCommandDescriptor names one world.Service write command AND the single
// taxonomy kind its envelope declares. It is one member of the EXPLICIT closed
// write-command construct the census (05-11) derives the write-command surface
// from — NOT name-prefix inference over method declarations, and NOT the
// incomplete world.Mutator interface subset (Codex finding 10).
type WriteCommandDescriptor struct {
	// Command is the stable world.Service write-command method name.
	Command string
	// Kind is the single taxonomy kind the command's envelope declares. ...
	Kind string
}
```

**Copy:** the doc-comment convention — the type comment states *what the census derives from it*
and *what it deliberately is not*. `WriteCommandDescriptor` has **exported** fields (it is a
descriptor, not a capability), so it is the analog for the census/doc idiom, **not** for opacity.

**Precedent the caller type must DEVIATE from — panic-on-empty:**

```go
// internal/access/prefix.go:95-112 (verbatim)
// PluginSubject returns a properly formatted plugin subject identifier.
// Panics if name is empty, since an empty subject bypasses access control.

	if name == "" {
		panic("access.PluginSubject: empty name would bypass access control")
	}
	return SubjectPlugin + name

// CharacterSubject returns a properly formatted character subject identifier.
// ...
// Panics if charID is empty, since an empty subject bypasses access control.
func CharacterSubject(charID string) string {
	if charID == "" {
		panic("access.CharacterSubject: empty charID would bypass access control")

	return SubjectCharacter + charID
```

`PlayerSubject` (`:121-126`) and `ViewerSubject` (`:153-168`) do the same — **four for four**. This
is the repo's uniform convention, and copying it into `HumanCaller` is the single most likely
planner mistake.

> **`HumanCaller("")` MUST NOT panic.** RESEARCH Pitfall 1: nine subtests of
> `TestWorldService_MalformedAccessParams` (`internal/world/service_test.go:6079`, empty-subject
> calls at `:6103,6124,6144,6166,6181,6199,6214,6234,6252`) assert
> `*_ACCESS_EVALUATION_FAILED`, produced by the `checkAccess` guard at `service.go:215-225` because
> `types.NewAccessRequest` rejects an empty subject. Criterion 3 forbids assertion rewrites.
> **Both sides of the precedent belong in the constructor's doc comment**: cite the four
> `access.*Subject` panics as the convention, and state that the fail-closed guard already lives
> one layer down and is asserted by `TestWorldService_MalformedAccessParams`.

**The system-context marker the caller derives** (`internal/access/context.go`, full file):

### `internal/world/service.go:209-254` — `checkAccess` (service, authz seam)

**Analog:** itself. Everything except the signature and line `:214` stays byte-identical.

```go
// internal/world/service.go:209-226 (verbatim — the seam)
func (s *Service) checkAccess(ctx context.Context, subject, action, resource string, prefix entityPrefix) error {
	metricKey := strings.ToLower(string(prefix)) + "_access_check"
	failCode := string(prefix) + "_ACCESS_EVALUATION_FAILED"
	denyCode := string(prefix) + "_ACCESS_DENIED"

	req, reqErr := types.NewAccessRequest(subject, action, resource, nil)
	if reqErr != nil {
		// Defensive: all call sites should use typed helpers
		// (access.CharacterSubject, access.LocationResource, etc.) that panic on
		// empty input, and action strings are hardcoded literals. Kept as defense
		// in depth against future call sites that might bypass the typed helpers.
		errutil.LogErrorContext(ctx, "invalid access request",
			reqErr, "subject", subject, "action", action, "resource", resource)
		observability.RecordEngineFailure(metricKey)
		return oops.Code(failCode).
			Wrap(errors.Join(ErrAccessEvaluationFailed, reqErr))
	}
	decision, err := s.engine.Evaluate(ctx, req)
```

**Notes for the migration:**
- The `nil` at `:214` is the only argument that changes; the `subject` string still flows into
  every `errutil.LogErrorContext` / `slog.ErrorContext` at `:220-221, 228-229, 239-241`. Those
  four log sites need the caller's subject accessor, not the caller value (`slog` `static-msg` +
  `key-naming-case: snake` policy applies — `.claude/rules/logging.md`).
- The defensive doc comment at `:216-219` explicitly cites "typed helpers … that panic on empty
  input" as the reason the branch is defensive. Once `HumanCaller("")` deliberately does **not**
  panic, this comment becomes load-bearing rather than defensive and **must be amended in the
  same commit**, or it will read as a false claim to the abac-reviewer (criterion 5).
- `decision.PolicyID()` / `decision.Reason()` at `:240,245,249-250` are the method-value trap
  already handled correctly — mirror the parens discipline in any new code.

**Representative command signature** (`internal/world/service.go:256-264`, verbatim) — the shape

**The parse machinery to extend** (`:111-158`, verbatim):

```go
// serviceMutatingMethods parses internal/world/service.go and returns, via go/ast,
// the set of *Service methods whose body routes through the write executor
// (references the `s.mutator` selector) — the structural "mutating method" signal —
// plus the full set of *Service method names.
func serviceMutatingMethods(t *testing.T) (mutating map[string]struct{}, allMethods map[string]struct{}) {
	t.Helper()
	root := findRepoRoot(t)
	src := filepath.Join(root, "internal", "world", "service.go")

	fset := token.NewFileSet()
	file, err := parser.ParseFile(fset, src, nil, 0)
	require.NoError(t, err, "parse internal/world/service.go")

	mutating = map[string]struct{}{}
	allMethods = map[string]struct{}{}
	for _, decl := range file.Decls {
		fn, ok := decl.(*ast.FuncDecl)
		if !ok || fn.Recv == nil || len(fn.Recv.List) == 0 {
			continue
		}
		recvName, ok := serviceReceiverName(fn.Recv.List[0])
		if !ok {
			continue // not a *Service (or Service) method
		}
		allMethods[fn.Name.Name] = struct{}{}
		if bodyReferencesSelector(fn.Body, recvName, "mutator") {
			mutating[fn.Name.Name] = struct{}{}
		}
	}
	return mutating, allMethods
}

// serviceReceiverName returns the receiver variable name for a method whose
// receiver type is *Service (or Service), and whether it is a Service method.
func serviceReceiverName(recv *ast.Field) (string, bool) {
	expr := recv.Type
	if star, ok := expr.(*ast.StarExpr); ok {
		expr = star.X
	}
	ident, ok := expr.(*ast.Ident)
	if !ok || ident.Name != "Service" {
		return "", false
	}
	if len(recv.Names) == 0 {
		return "", false
	}
	return recv.Names[0].Name, true
}
```

Note `serviceMutatingMethods` **already returns `allMethods`** — the new census's universe is
that second return value, already computed and today discarded (`mutating, _ :=` at `:188`).
`bodyReferencesSelector` (`:162-180`) is the reusable `ast.Inspect` walker; a
`bodyReferencesSelector(fn.Body, recvName, "checkAccess")` call is the natural structural
predicate for "this method performs an authorization check" — the exact discriminator the
`UpdateCharacterPreferences` exemption needs (`service.go:851-856` deliberately runs no
`checkAccess`). **Preferring that structural predicate over a hand-written name exemption list is
the stronger design**, because it is self-maintaining; if the plan uses a name list instead,
follow the exemption idiom already in this file:

