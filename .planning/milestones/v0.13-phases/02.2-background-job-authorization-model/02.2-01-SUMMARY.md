
`Name: "seed:job-fixture-instance-scoped"`, `SeedVersion: 1`.

### `trigger_subject` normalization (A6, settled)

`trigger_subject` carries the **BARE aggregate ULID** — byte-identical to `bags.Resource["id"]`, which the resolver stamps provider-independently as the substring after the first `:` of the resource ref (`resolver.go:213`).

It is **NOT** a dotted NATS subject (`events.<game>.character.<id>`) and **NOT** a prefixed entity ref (`character:<id>`). Either compares unequal against `resource.id` and every job write silently default-denies. **Phase 3 plan 03-04 copies this spelling byte-for-byte.**

The action bag keys, exactly as the engine sees them:

```text
job.trigger_event_id
job.trigger_event_type
job.trigger_subject
```

### Caller signatures (verbatim)

```go
type Provenance struct {
	EventID   string
	EventType string
	Subject   string // the BARE aggregate ULID
}

func JobCaller(name string, prov Provenance) Caller
func ScheduledJobCaller(name string) Caller
```

Neither takes a `map[string]any`, a variadic option, or any other channel for caller-chosen keys. `JobCaller` panics on an empty name (inherited from `access.JobSubject`), deviating from `HumanCaller` deliberately.

### `jobs.Registry` API Phase 3 subsystems will call

```go
func NewRegistry() *Registry
func (r *Registry) Register(name string, writes []string) error // JOB_REGISTRATION_INVALID on empty name or empty writes
func (r *Registry) Unregister(name string)                      // idempotent
func (r *Registry) IsJobRunning(name string) bool
func (r *Registry) DeclaredWrites(name string) ([]string, bool)  // returns a defensive copy
```

Zero dependencies, injected through config — **not** a `lifecycle.Subsystem` (assumption A5 held; no `SubsystemID` was minted, so the pinned 18-element topological start order was not touched).
