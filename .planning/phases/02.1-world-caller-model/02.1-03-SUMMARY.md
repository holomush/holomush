## Deviations from Plan

### 1. [Rule 2 - Correctness] The census parses all of `internal/world/`, not `service.go` alone

**Found during:** Task 1, writing the collector.

**Issue.** The plan and the existing `serviceMutatingMethods` both parse
`internal/world/service.go` only. Every `*Service` method lives there today (verified:
`rg -c '^func \([a-z]* \*Service\) ' internal/world/*.go` → `service.go:29`, no other
file), but a future `service_read.go` would silently carry its commands out of the
census — and INV-WORLD-8's summary claims "every public `world.Service` command",
not "every command in one file".

**Fix.** `worldServiceCommands` walks every non-test `.go` file in `internal/world/`.
Cost is one `os.ReadDir`; the failure messages name the declaring file. This strengthens
the binding to match the summary rather than narrowing the summary to match the test.

**Commit:** `bfc56784b`.

### 2. [Rule 2 - Correctness] A second `// Verifies: INV-WORLD-8` added to `internal/world/caller_test.go`

**Found during:** Task 2, writing `asserted_by`.

**Issue.** `.claude/rules/invariants.md` binds an invariant via a `// Verifies:`
annotation and lists the annotated file(s) in `asserted_by`. Listing
`internal/world/caller_test.go` in `asserted_by` while only the census file carried an
annotation would leave the registry internally inconsistent — the file would be claimed
as a binding site with no discoverable binding.

**Fix.** Added the annotation above `TestWorldServiceCallerAttributesReachActionBag`, the
paired permit/deny proof that genuinely asserts the attribute-forwarding clause, with a
sentence naming which half of INV-WORLD-8 it proves. `internal/world/caller_test.go` is
outside this plan's declared `files_modified`; the change is one comment block, no
assertion touched. `TestBoundInvariantsAreGenuinelyAsserted` is unaffected (it fails only
when **every** site is a placeholder).

**Commit:** `bfc56784b`.

   noise that contradicts the plan's own "self-maintaining … needs no list of the 23
   command names" design goal. The count is recorded above instead; the test asserts the
   *shape*, which is the invariant.
