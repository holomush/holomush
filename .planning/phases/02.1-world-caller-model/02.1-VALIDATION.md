- **After every task commit:** `task lint` + `task test -- ./<touched packages>/` — D-64 requires green per commit.
- **After every plan wave / before the flip commit lands:** `task test` (full untagged suite) **and** `task test:int`. `task test:int` is **mandatory, not optional** — `task test` does not compile the 43 `//go:build integration` call sites this refactor touches.
- **Before `/gsd-verify-work`:** `task pr-prep` green (run inline in the parent), then `/holomush-dev:review-abac` → READY.
- **Max feedback latency:** ~60s for the world unit tier; full+integration is a wave-boundary gate, not a per-task gate.

Reconciled against `e124617b4`. Evidence for the green rows: `task test` PASS
(11852 ok / 4 skipped) on this tree, plus CI `success` at `07ca74c46` for the
integration and E2E tiers. Every named test symbol in the map above was checked
for **existence** as well as exit status, because `go test -run <NoSuchTest>`
exits 0 — a map naming a test that does not exist reports green vacuously.

**Escalated — D-63 is not met at HEAD.** The row asserts "the committed codemod
re-run yields an empty diff." Four of the five rules in `scripts/codemod/` re-run
clean; `world-caller-arg2.yml` matches `internal/world/grpc_server_test.go:329`,
where argument 2 is **already** a `world.Caller`. The rule's `(?i)subj` allowlist
fires on the `Subject:` field key inside a nested `world.Provenance{...}`
literal, and the rule's own documented apply command (`-U`) would rewrite the
site to `world.HumanCaller(world.JobCaller(...))` — flipping the principal from
job to human and destroying the assertion that test exists to make.

This is **cross-phase drift, not a 02.1 defect**: the guard enumerates the three
post-flip shapes that existed when 02.1 shipped, and Phase 02.2 later introduced
a fourth (composite literal nested inside a constructor call). Latent — severity
`help`, and the rule is a local developer step, never a CI gate.

Tracked as **#4993**. `nyquist_compliant` stays `false` until it re-runs clean.
