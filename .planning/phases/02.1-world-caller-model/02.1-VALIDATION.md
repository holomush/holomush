---

## Sampling Rate

- **After every task commit:** `task lint` + `task test -- ./<touched packages>/` — D-64 requires green per commit.
- **After every plan wave / before the flip commit lands:** `task test` (full untagged suite) **and** `task test:int`. `task test:int` is **mandatory, not optional** — `task test` does not compile the 43 `//go:build integration` call sites this refactor touches.
- **Before `/gsd-verify-work`:** `task pr-prep` green (run inline in the parent), then `/holomush-dev:review-abac` → READY.
- **Max feedback latency:** ~60s for the world unit tier; full+integration is a wave-boundary gate, not a per-task gate.
