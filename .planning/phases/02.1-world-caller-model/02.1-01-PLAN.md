`Caller` with three unexported fields: a subject string, a system bool, and an attribute map of
`map[string]any`. Export exactly two constructors — `HumanCaller(subjectID string) Caller` and
`SystemCaller() Caller`. `SystemCaller` derives its system flag itself and hardcodes the bare
subject the S1 gate compares against; it takes no parameters, so a system caller cannot be
misconstructed. `HumanCaller` never sets the system flag and never re-derives or re-prefixes the
string it is handed — it wraps the already-built subject verbatim, because that same string becomes
the world-change outbox envelope actor. Neither constructor populates the attribute map in 02.1.
