# Phase 06.1 Plan 06: The cross-language parity guard Summary

**Three things were hand-duplicated across the Go/TypeScript boundary with nothing enforcing any of them — the writable path set, the two byte caps and the path-to-cap mapping — and all three now fail `task test` on drift, from a Go test that holds the unexported allowlist and the world constants as live symbols and reads the Sheet as text.**

## Performance

- **Duration:** 24 min
- **Tasks:** 2
- **Files modified:** 4 (1 created, 3 modified)

## Accomplishments

- **`TestAdminEditableFieldsInTheWebSheetMatchTheServerMaskAllowlist`** in `package grpc` parses `ADMIN_EDITABLE_FIELDS`, `SHORT` and `LONG` out of the Sheet and compares them against `adminProfileMaskablePaths`, `world.MaxNameLength` and `world.MaxDescriptionLength` — set equality in both directions, both caps by value, and per-path cap agreement.
- **The mapping is covered because it is read from the constructor.** `line` means the short cap and `prose` the long one, so a `line` that should have been a `prose` is caught by the per-path assertion that set equality alone stays green under.
- **The anti-vacuity preconditions run before any comparison.** A renamed array, a reformatted entry or a moved file fails on the precondition rather than passing for having compared two empty sets. Demonstrated live.
- **The self-comparing web-side block is gone, not supplemented.** Its length, its 7/6 split and its literal path array are deleted; what remains are four properties the module cannot satisfy by echoing itself — unique paths, unique non-empty flat wire names, and exactly two caps partitioned by kind with the line cap strictly smaller.
- **Two doc comments stopped claiming an unenforced relationship.** The Sheet's module doc said "nothing below tries to enforce membership"; that sentence is now false and was replaced by a naming of the guard. `SHORT`/`LONG` keep their Go constant names and gain the note that both are asserted against those constants by value.

## Decisions Made

- **`package grpc`, not `test/meta`.** The authority is unexported. In `test/meta` the guard would compare a `go/ast` re-parse of the map against a parse of the TypeScript — two derived readings, neither the value the server enforces. Here the map is a live symbol and only one side needs parsing.
- **A parsing guard, not codegen or a shared schema.** Thirteen strings and two integers that change roughly never do not pay for a generator, a Taskfile target and a stale-diff check. The in-tree precedent is `test/meta/web_error_boundary_census_test.go`, added by this same phase.
- **The mapping read from the constructor.** `line`/`prose` IS the mapping; a separate table would be a fourth thing to keep in step.
- **The web-side block replaced rather than extended,** because its assertions were a transcription and a coordinated edit passes a transcription.
