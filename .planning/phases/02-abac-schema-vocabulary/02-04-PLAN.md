<objective>
Land the character lifecycle vocabulary as a usable domain concept and bind the two
invariants 01-SPEC.md §13 assigns to Phase 2: INV-WORLD-5 (exhaustive lifecycle
reads) and INV-WORLD-6 (retire preserves the name reservation).

Migration `000054` (plan `02-01`) added the columns. This plan makes them mean
something: a closed Go vocabulary, one selection predicate every read routes
through, and the two tests that prove the unreachable `idle` value is covered
non-vacuously and that retirement does not free a name.

Purpose: §4.3 is explicit that shipping a value nothing can reach is safe **only**
when paired with the exhaustive-read rule. An unreachable enum value plus a
non-exhaustive check reads correct for exactly as long as the value stays
unreachable, and fails open on the day a later milestone makes it reachable — a
change made by someone with no reason to audit every lifecycle read.
Output: `internal/world/lifecycle.go`, an exhaustive `Selectable` decision, and two
bound registry invariants.

**Requirement mapping note.** This plan's ROADMAP obligation is the phase-goal item
"the character **lifecycle column**". Of the six requirement IDs allocated to
Phase 2, IDENT-09 is the one it advances: INV-WORLD-6's guarantee — that a name
stays reserved through retirement and is released only by the delete path — is a
statement about exactly the name-reservation surface IDENT-09's unique index
enforces, and the two are asserted against the same column.
</objective>

  <action>
Create `internal/world/lifecycle.go` with `type Status string`, the three exported
constants, `func ParseStatus(s string) (Status, error)` returning
`oops.Code("INVALID_CHARACTER_STATUS")` on anything outside the closed set, and
`func Selectable(s Status) bool`.

`Selectable` MUST be an exhaustive `switch` over the three constants with a
`default:` arm returning false. It MUST NOT be `s != StatusActive`, and it MUST NOT
be `s == StatusActive`. The difference matters: §4.3's rule is that the default arm
**denies**, so a value added later is excluded by the same code path that excludes
`retired`, without a second predicate to keep in sync. Carry that reasoning in the
function's doc comment.

Add `NeverActive int64 = 0` beside them, documented as the never-active sentinel:
`0` is the minimum, so a most-recent-first sort places never-active rows last
without a `NULLS LAST` clause, and any "last active" rendering MUST special-case it
rather than displaying 1970 (D-25).

Extend `world.Character` with `Status Status` and `LastActiveAt int64`. Set
`Status` to `StatusActive` and `LastActiveAt` to `NeverActive` in
`NewCharacterWithID`. Extend `Validate()` to reject a `Character` whose `Status` is
outside the closed set.

Extend every `SELECT` column list and every scan in
`internal/world/postgres/character_repo.go` to carry `status` and `last_active_at`,
in lockstep — a column list updated in four of five places produces a scan-count
mismatch at runtime, not at compile time. Do **not** add a write path for
`last_active_at`: D-24 assigns the write seam to Phase 3, and it MUST NOT hook the
lease-refresh path (`internal/session/session.go` `RefreshConnection`), which would
make every character a hot write per lease interval.

Route `internal/grpc/auth_handlers.go`'s `SelectCharacter` eligibility decision

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored `characters.status` → selection decision | A lifecycle value the reader does not recognize decides whether a character can be played. |
| retired character → name space | A freed name inherits the identity of every denormalized historical occurrence of it. |

| T-02-17 | Elevation of privilege | `world.Selectable` | high | mitigate | A non-exhaustive check plus an unreachable enum value fails open on the day the value becomes reachable. Closed by an exhaustive `switch` with a denying `default`, proven by a directly-constructed `idle` row. |
| T-02-18 | Spoofing | name released on retire | high | mitigate | A freed name claimed by a new character inherits every archived pose, published scene and rendered export naming it — surfaces no later write can reach.
