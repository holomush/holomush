<objective>
Land IDENT-09's database guarantee: the Go backfill and duplicate detection, the
`SET NOT NULL` then `CREATE UNIQUE INDEX` that constrains the normalized key, the
operator command that resolves a collision, and the concurrent-claim gate
demonstrated RED against today's unindexed schema first.

Purpose: uniqueness today is a check-then-insert sequence with a window between the
check and the write. §6.1.3 is explicit that uniqueness is a database constraint,
not an application check. Plan `02-06` made the gate the only way a name is
admitted; this plan makes the database the thing that decides whether the name is
free.
Output: migrations `000055` (Go backfill + detection) and `000056` (constrain), the
shared character fixture helper the `NOT NULL` forces, a
`holomush character name` resolution command, and the two integration specs.

**Research blocker incorporated (RESEARCH § Concerns 2).** D-20 gated Phase 2
execution on goose adoption. That work has landed: `internal/store/migrations/`
holds single-file goose migrations through `000053`, `internal/store/migrate.go`
wraps `goose.Provider`, Go migrations are supported, and
`internal/store/migrate_gointerleave_integration_test.go` already ships a fixture
chain demonstrating D-21's exact A→B→C sequence with C's ordering rationale
documented in its own constants. **Treat that file as the worked example rather
than deriving the shape again.** One caution the fixture itself flags: it passes
`goose.WithDisableGlobalRegistry(true)` because it is a fixture, and the production
provider MUST NOT — doing so would make `000055` invisible to the real chain.

**Writer-boundary constraint (why `000055` carries no SQL).**
`test/meta/world_sql_fence_test.go`'s Go scan walks the whole tree, exempts only
`internal/world/postgres`, `_test.go` files, generated files and a skip set that
its own self-test at `:306-309` proves **excludes `internal/store`**. The
`world-sql-fence:allow` escape hatch lives only in `scanMigrationForWorldDML`,
which globs `*.sql` — **there is no marker path for `.go` files.** A backfill
written as raw `UPDATE characters` inside `000055.go` is therefore an unexemptable
fence violation against a bound invariant. Plan `02-06` put the statement inside
the writer boundary as `worldpostgres.BackfillCharacterIdentity`; `000055` is a
caller. `000056` is `.sql` and carries schema DDL only, which the migration scan
permits by construction (`TestWorldSQLFenceAllowsMigrationDDL`).

**Scope note (recorded, not a reduction).** This plan was split out of a single
oversized `02-06`, which now owns the admission token, the gated writer boundary
and the five-site `ExistsByNormalizedName` migration. Success criteria 1 and 2 are
**not** amended; they are discharged across the pair. Criterion 1's "at rename"

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent create requests → `characters.name` | Two requests race for one in-world identity; the window between the existence check and the insert is the vulnerability. |
| operator → duplicate resolution | A human decides which of two colliding characters keeps its name, and supplies the replacement. |
| migration runner → production schema | A DDL step whose precondition is another step having run. |
| operator → a server that will not start | The resolution command must work in exactly the state that makes the server refuse to boot. |
