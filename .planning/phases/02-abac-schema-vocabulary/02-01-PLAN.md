`func Skeleton(s string) string` implementing UTS #39 §4's core: `norm.NFD` →
per-rune substitution from `confusables` → `norm.NFD` again. Record in a doc
comment that this is `bidiSkeleton(LTR, ·)` reduced for same-direction comparison,
that no surveyed Go package implements the RTL form, and that the comparison in
this system is always same-direction (stored skeleton vs candidate skeleton).

**Layer 3 — pipeline.** Create `internal/charname/pipeline.go` with
`type Normalized struct { Display, Key string }` and
`func Normalize(submitted string) (Normalized, error)` implementing §6.1.1 in
exactly this order: (1) `norm.NFKC`, (2) `runes.Remove(runes.In(unicode.Cf))`
composed through `transform.Chain`, (3) whitespace canonicalization by
`strings.Fields` + `strings.Join` with a single `U+0020` — reuse that half of
today's `world.NormalizeCharacterName`, drop its per-word title-casing — producing
`Display`; then (4) `golang.org/x/text/cases.Fold()` over `Display` producing
`Key`. Use `cases.Fold()`, never `strings.ToLower` — step 4 is Unicode full case
folding. Return `oops.Code("NAME_EMPTY_NORMAL_FORM")` when `Display` is empty.

**Layer 4 — gate.** Create `internal/charname/gate.go` with
`type SkeletonLookup interface { SkeletonExists(ctx context.Context, skeleton string) (bool, error) }`,
`type Gate struct { Skeletons SkeletonLookup }`, and
`func (g *Gate) Check(ctx context.Context, submitted string) (Normalized, string, error)`

`Skeleton(n.Key)`, calls `SkeletonExists`, and returns `oops.Code("NAME_CONFUSABLE")`
on a hit. The error message MUST NOT name or identify the colliding character.
`gate.go` is the single composition point every later mechanism plugs into — later
plans add steps here rather than at call sites.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| player → `CharacterService.Create` | An attacker-chosen name string crosses into the world model and becomes an in-world identity other characters read and act on. |
| unicode.org → generator → repo | A third-party data file becomes compiled-in security-gate data. Crossed once, at generation time, by a developer. |
| Go module proxy → `go.mod` | A dependency promotion (`golang.org/x/text` indirect → direct) changes the supply-chain surface of a security gate. |

| T-02-01 | Spoofing | `charname.Skeleton` / create path | high | mitigate | Whole-script homoglyph impersonation is closed by the skeleton check against `characters.name_skeleton`, proven by the integration spec seeding a Latin name and rejecting its Cyrillic clone. |
| T-02-02 | Spoofing | `charname.Normalize` step 2 | high | mitigate | Invisible-codepoint padding (ZWJ/ZWNJ/bidi overrides) is closed by `Cf` stripping, which runs before the key is computed so two visually identical strings collapse to one key. |
