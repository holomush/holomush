## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JetStream -> retirement reactor | At-least-once delivery of attacker-influenceable-in-timing messages into a privileged host loop. |
| JetStream -> activity listener | Broad `events.>` subscription; every event's `Actor` is untrusted input to the KV key. |
| host process -> NATS KV | New persistent server-side state (a bucket) with no prior in-repo precedent. |

| T-03-11 | Denial of Service | KV bucket unbounded growth if the flusher stalls | medium | mitigate | `History: 1` so only the latest revision per key is retained; the throttle bounds write rate to one per character per window. `MaxBytes`/`TTL` are available knobs if growth is observed. |
