<objective>
Close the holomush command package's coverage floor gap, measured honestly against a
denominator that now includes the two wiring files this phase stopped ignoring.

Purpose: this is the second and larger of the two named coverage floors. Two things changed
under it before this plan runs: the end-to-end coverage session now actually lands, which
should lift the package substantially on its own, and the two wiring files are no longer
excluded, which enlarges the denominator by roughly 656 statements. Neither effect can be
predicted — both must be measured before any test is written, or this plan will either write
tests for code the end-to-end session already covers or chase a target that has already moved.

Output: a measured starting position, targeted behavioural tests for what genuinely remains
uncovered, and an honest statement of the residual if the floor is not reachable without
theatre.

Decisions implemented: D-01 (the named floor set must be cleared; this is the second and larger
of its two remaining gaps), D-03 in its reversed form (the wiring files are measured rather than
ignored, so the denominator is honest), D-05 (no coverage theatre — an unreachable floor is
recorded as a residual rather than fabricated).
</objective>
