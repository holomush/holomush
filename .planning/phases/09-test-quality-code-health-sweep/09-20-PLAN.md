<objective>
Build the three QUAL-04 harness seams the session-matrix spec plans assume but the harness does
not have, and prove each one independently before any matrix row is written against it.

Purpose: cross-AI review established that three of the matrix's transition families are written
against harness capabilities that do not exist. The telnet session opener is fatal on call, so
the telnet column — which D-12 calls the highest-value one — has no seam at all. The expiry
helper writes a row state the production reaper provably never selects, so every reaper assertion
built on it would pass while proving nothing. And the default command registry is empty, so the
quit command is not dispatchable. Each would have produced a green spec that verifies nothing,
which is the exact defect this phase exists to eliminate.

Output: three seams, each landing with its own smoke spec, before the matrix registry is written —
so the registry's dispositions can be based on what the harness can actually do rather than on
what a plan assumed it could.

Decisions implemented: D-12 (the telnet column stays in scope; this plan makes it real rather than
re-scoping it away), D-15 (no sleeps anywhere — the reaper seam is driven by explicit row state
and the reaper's own injectable clock).

Addresses review concerns B1 (telnet opener fatal), B2 (the expire helper cannot drive the
reaper), and B3 (the quit command is not dispatchable from harness defaults).
</objective>
