<objective>
Add the missing index on the sessions table's location column as migration 000053.

Purpose: presence — the who-is-here query that drives every location view — filters sessions
by location, and that column has no index across all 52 existing migrations. Three indexes
exist on the sessions table and none of them covers this access path; two similarly named
indexes on other tables make the gap easy to misread as already closed. Under load this is a
sequential scan on the hottest read path in the game loop.

Output: a paired, idempotent index migration following the shape every other index migration
in this repository already uses.

Decisions implemented: D-17 (one of the four Medium-cluster items that land), D-19 (plain
idempotent index creation with a paired idempotent drop — no concurrent build, for which this
repository has no precedent and no non-transactional runner support).
</objective>
