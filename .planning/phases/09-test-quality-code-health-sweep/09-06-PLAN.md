<objective>
Make the plugin downgrade fence's dropped-audit-record path observable.

Purpose: when the fence has no audit emitter configured it returns early and the violation
record is discarded with no log and no metric. An audit record lost without a trace is
unattributable — the operator cannot distinguish "no violations occurred" from "violations
occurred and the record went nowhere". The surrounding function already logs its timeout
branch in exactly the required form twelve lines below the defect, so the pattern to copy is
in the same function.

Output: a log line on the drop path with the plugin name and event type, carrying the request
context, and a test that fails if the drop goes silent again.

Decisions implemented: D-17 (one of the four Medium-cluster items that land; the crypto domain
review gate fires for this surface even though the DEK read-cache item is deferred).
</objective>
