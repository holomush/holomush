  <action>
Create `internal/grpc/characteraccess_write.go` with `UpdateCharacterProfile` on
`CharacterAccessServer`.

Declare `updateCharacterProfileMaskablePaths` as a package-level map keyed by the
exact path string, carrying exactly the twelve section 7.2 profile field paths
and nothing else — copying `updateSceneMaskablePaths`' shape and its rationale
comment about not letting a direct gRPC caller drive an unadvertised mutation
through the mask. Paths are compared by exact-string map lookup: no prefix
matching, no wildcard, no glob, no dotted-subtree expansion.

Gate ordering is normative and follows the precedent exactly: resolve the
session, resolve ownership, reject the version if it is absent or zero, validate
the mask against the allowlist, short-circuit an empty mask as a no-op success,
then validate values, then call the domain write. Authorization is asserted
before the mask is applied, and the empty-mask short-circuit sits after
authorization so a no-op cannot be used by an unauthorized caller to drive
downstream work or as an existence oracle.

Treat the mask as a **set**: normalize it before use so ordering is irrelevant
and a duplicated entry applies once.

Enforce the caps in the handler, where the error code and the wire status live
(D-82). Reuse the shipped world constants rather than minting new numbers: the
short single-line fields — pronouns, concept, species, age, faction, currently,
timezone — cap at `world.MaxNameLength`; the long multi-paragraph fields —
appearance, personality, biography, rumors, rp_preferences — cap at
`world.MaxDescriptionLength`. Apply the same valid-UTF-8 and
control-characters-except-newline-and-tab rules `world.ValidateDescription`
applies, and measure length in **bytes** exactly as that function does, so the
facade and the domain cannot disagree about where the boundary is. Say "bytes" in
the doc comment.

Map errors per 01-SPEC section 9.6: an absent or zero version is the
version-required code at invalid-argument; an unlisted mask path is the
mask-path-unsupported code at invalid-argument; a non-owned character is the
not-found-equivalent; a stale version is the shipped concurrent-edit code at
aborted — Phase 4 introduces this wire mapping, no facade carries it today, and
the loser is surfaced rather than retried, because a retry loop at the facade
would reintroduce last-write-wins one layer up. The wire message stays generic
and never interpolates an inner error; the structured reason goes to
`errutil.LogErrorContext`.

Assert wire outcomes in the tests with `status.Code` and
`status.Convert(...).Message()`. Do not assert the wire with a chain-walking oops
helper — it resolves the deepest code in the chain and is not evidence about what
the wire carried; it remains correct for asserting which internal code the
handler produced.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web form/button → typed mutation RPC | A machine-initiated structural write; the request body is untrusted and the mask is attacker-controlled |
| facade → `world.Service` write commands | The only write path; a repository call from the facade would bypass ABAC and the outbox |
| two concurrent writers → one character row | The optimistic-concurrency predicate is the only thing preventing a silent lost update |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Elevation of Privilege | `update_mask` handling | high | mitigate | Closed exact-string allowlist of exactly twelve paths; unlisted path rejected with the mask-path-unsupported code; empty-mask short-circuit placed after ownership |
| T-04-19 | Tampering | absent or zero `expected_version` | high | mitigate | Rejected at the RPC boundary before any domain call, asserted with a domain double that fails on invocation; never defaulted to the row's current version |
| T-04-20 | Tampering | concurrent mutation | high | mitigate | Shipped CAS predicate surfaced as an aborted status; no facade-level retry, which would reintroduce last-write-wins |
| T-04-06 | Elevation of Privilege | structural write routed through the command parser | medium | mitigate | Typed RPC only; no reference to the command dispatcher in the facade or the proxy (ADR governing the gateway boundary) |
| T-04-21 | Tampering | oversized or malformed prose input | medium | mitigate | Byte-measured caps reusing the shipped world constants, plus the shipped UTF-8 and control-character rules; boundary cases asserted at the cap and one byte past it |
