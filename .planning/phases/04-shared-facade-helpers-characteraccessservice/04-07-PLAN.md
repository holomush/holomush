## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous web reader → directory RPC | Bulk enumeration by an unauthenticated caller; the response shape is the whole protection |
| directory handler → reachability evaluation | Per-character policy decision; a failure here must not silently shrink the result |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-23 | Information Disclosure | directory response message | high | mitigate | `PublicCharacterSummary` carries id and name only; the four presence-telemetry fields have no field to occupy, so the exclusion is a descriptor property rather than a handler discipline |
| T-04-01 | Information Disclosure | directory membership | high | mitigate | An unreachable character is absent, and the absence-versus-nonexistence equality is asserted by comparing whole responses |
| T-04-04 | Tampering | reachability pass failure | medium | mitigate | An evaluation failure aborts the call with an internal status; the handler never returns a silently shortened list |
| T-04-24 | Information Disclosure | nondeterministic enumeration order | low | mitigate | Deterministic sort before return, asserted by marshaling the same response twice and comparing bytes |
| T-04-25 | Tampering | a surviving forwarder for the removed RPC | medium | mitigate | Total removal asserted by a repository-wide search excluding regenerated files; no alias, no deprecation stub |
