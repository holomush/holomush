## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous/guest viewer → profile read path | Untrusted; the viewer's rung is derived server-side and is the only input to the floor decision |
| facade → ABAC engine | Every per-field decision is the engine's; the facade composes, it does not decide |
| response message → client | The wire is the enforcement surface; the client is not a participant in the visibility decision |
