## Pattern Assignments

### `internal/access/policy/attribute/job_provider.go` (provider, resolve)

**Analog:** `internal/access/policy/attribute/plugin_provider.go` — **whole file, 63 lines**.
Verbatim body is in `02.2-RESEARCH.md` §Pattern 1; do not re-read it.

Four structural elements to copy, in order (`plugin_provider.go:12-62`):

1. **Registry interface, declared in the provider's own file** (`:12-15`):
```go
// PluginRegistry checks whether a plugin is currently loaded.
type PluginRegistry interface {
	IsPluginLoaded(name string) bool
}
```
→ `JobRegistry { IsJobRunning(name string) bool }` plus, for D-50, a declared-writes lookup
(e.g. `DeclaredWrites(name string) ([]string, bool)`) so `writes` has a source.

2. **Two-phase init setter** (`:27-33`) — `SetRegistry(r PluginRegistry)`. This exists because
   `setup.go:320` constructs the provider with a **nil registry** and the real one is attached
   later. The job registry has the same ordering problem (registry lives in a subsystem built
   after `BuildABACStack`), so **copy `SetRegistry`, and copy the doc comment's justification**.
   `ABACStack` exposes it as a struct field (`setup.go:415` `PluginProvider: pluginProvider`) —
   a `JobProvider` field is the mirror.

3. **`Namespace()` / `ResolveSubject` / `ResolveResource` / `Schema()`** — the 4-method
   `AttributeProvider` surface. Note `PluginProvider.ResolveSubject` returns
   `map[string]any{"name": subjectID}` with the **raw `subjectID`** — see the correctness note below.

4. **`Schema()` is load-bearing** (`:56-62`): `mergeAttributes` drops unregistered keys.
   D-50's `writes` MUST be `types.AttrTypeStringList` (RESEARCH Pitfall 5).

**⚠️ Correctness delta the analog does NOT show — verified this session at
`internal/access/policy/attribute/resolver.go:350-395`:**

```go
func (r *Resolver) resolveEntity(ctx context.Context, resolveType, entityRef string, bag map[string]any) error {
	for _, namespace := range r.providerOrder {
		provider := r.providers[namespace]
		...
		attrs, err := r.safeResolve(ctx, provider, resolveType, entityRef)   // <-- FULL ref, EVERY provider
```

`entityRef` is passed **unmodified** to **every** provider. So `PluginProvider` is called with
`"character:01ABC"` too, and its own `IsPluginLoaded` is what makes that return `nil, nil`.
**The job provider MUST add an explicit `strings.HasPrefix(ref, access.SubjectJob)` guard and
strip the prefix before the registry lookup** (RESEARCH Pitfall 4). Also note the consequence:
`PluginProvider` stamps `plugin.name = "plugin:foo"` (prefixed) — do **not** copy that; the job
provider should stamp the bare name so `principal.job.name == "retirement"` reads naturally and
matches `bags.Subject["id"]` (`resolver.go:195-198`).

### D-66 — the three compiler↔schema wiring sites (**the phase's riskiest change**)

**Site 1 — `internal/access/setup/setup.go:146-161` (the production stack builder).**
Verbatim, with the surrounding context that makes the ordering trap visible:

```go

	// 2-3. Schema and compiler

	compiler := policy.NewCompiler(schema)        // <-- 151

	// 4-5. Cache with initial load

		return nil, eb.Wrapf(err, "cache initial reload failed")
```

Providers register at `:163-323`; the last is `pluginProvider` at `:319-323`; the seed-coverage
sweep at `:335`. **The reload at `:155` must move to after `:323`** (RESEARCH Pitfall 2), and
`:150-151` must become `policy.NewCompiler(schemaReg.Schema())` — but `schemaReg` is allocated at
`:160`, *after* the compiler. So the minimal correct diff is a **three-way reorder**:
allocate `schemaReg`/`resolver` first → register all providers → `Register(schemaReg, "action", …)`
→ construct compiler on `schemaReg.Schema()` → construct cache → `cache.Reload`.

**A4 trace result (research flagged this as untraced — resolved here):** the reload move is
**safe**. `ps.SetOnMutate(...)` is wired at `setup.go:380-390`, and `healthTracker` at `:360-376`
— both are constructed *after* the whole provider block, so neither depends on the reload having
already run. Verbatim:

```go

	ps.SetOnMutate(func(ctx context.Context) {
		invalidateCtx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
		defer cancel()
		if err := cache.Invalidate(invalidateCtx); err != nil {
			slog.ErrorContext(ctx, "cache invalidation after store mutation failed", "error", err)
			healthTracker.RecordFailure("invalidation failed: " + err.Error())
		} else {
			healthTracker.RecordSuccess()
		}
```

The poller (`:393-401`) is likewise constructed after. **Nothing between `:155` and `:323` reads
`cache`.** The reorder's only real constraint is that `cache` must exist before `:360`'s
`healthTracker` closure and `:380`'s `SetOnMutate` — both far below the provider block.

### D-67 — a boot-time compile failure that names its offender

**No single analog exists; the shape is composed from two existing sites, both verified verbatim.**

**Half 1 — the compiler names the KEY** (`internal/access/policy/compiler.go:147-171`):
```go
func (c *Compiler) validateAttributes(cb *dsl.ConditionBlock) ([]ValidationWarning, error) {
	refs := collectAttrRefs(cb)
	warnings := make([]ValidationWarning, 0, len(refs))

	for _, ref := range refs {
		if !c.schema.HasNamespace(ref.namespace) {
			continue
		}
		if c.schema.IsRegistered(ref.namespace, ref.key) {
			continue
		}

		fqn := ref.namespace + "." + ref.key
		if ref.namespace == "action" {
			return nil, fmt.Errorf("unregistered action attribute %q: action namespace is registered but attribute is not", fqn)
		}
		warnings = append(warnings, ValidationWarning{
			Message: fmt.Sprintf("unknown attribute %q in registered namespace %q", fqn, ref.namespace),
		})
	}
	return warnings, nil
}
```
Note: this is a **plain `fmt.Errorf`, not `oops`** — inconsistent with the repo convention. D-67's
"operator-actionable" obligation is a reasonable place to upgrade it to

### D-60 — the `action` schema registration call site

**Analog for the spelling** — `internal/access/policy/attribute/schema.go:33-67`. Package-level
function **and** receiver method both exist, so both spellings compile:

```go
func Register(r *SchemaRegistry, namespace string, schema *types.NamespaceSchema) error {
	if namespace == "" { return fmt.Errorf("namespace cannot be empty") }
	if r.schema.HasNamespace(namespace) { return fmt.Errorf("namespace already registered: %s", namespace) }
	if schema == nil { return fmt.Errorf("schema cannot be nil") }
	if len(schema.Attributes) == 0 { return fmt.Errorf("schema must have at least one attribute") }
	for key, attrType := range schema.Attributes {
		if attrType < 0 || attrType > types.AttrTypeStringList {
			return fmt.Errorf("invalid attribute type for %s.%s: %d", namespace, key, attrType)
		}
	}
	if err := r.schema.Register(namespace, schema); err != nil {
		return oops.Wrapf(err, "failed to register namespace %s", namespace)
	}
	return nil
}

// Register is the receiver method that delegates to the package-level function.
func (r *SchemaRegistry) Register(namespace string, schema *types.NamespaceSchema) error {
	return Register(r, namespace, schema)
}
```
D-60 names the package-level spelling `attribute.Register(schemaReg, "action", …)` — both work;
follow D-60.

range-checks the `AttrType`. And `IsRegistered(namespace, key)` (`schema.go:70-72`) is an exact
map lookup. So `"job.trigger_subject"` as a literal map key is legal and is the only spelling that
can match `compiler.go:161`'s `ref.namespace + "." + ref.key`. **A3 holds.**
