Reconciled against `e124617b4`. Every Wave-0 artifact landed; all automated rows
green (`task test` PASS — 11852 ok / 4 skipped — on this tree; CI `success` at
`07ca74c46` for the integration row). Both manual-only rows are discharged with
citations, so `nyquist_compliant` is `true`.

**Both gaps were map drift — the commands, not the coverage.** Each was a
predicted string that execution spelled differently, and each would have
misreported in a different direction:

1. **False-green risk.** The D-66 row invoked
   `-run 'TestValidateAttributes\|TestCompile'`. `TestValidateAttributes` was
   predicted at plan time from the unexported `compiler.validateAttributes`
   method and **never existed**; the real tests are
   `TestCompileValidatesAttributesIn{Has,Like,Contains}Condition`
   (`internal/access/policy/compiler_test.go:418,434,448`). Only the `TestCompile`
   alternative saved it — `go test -run <NoSuchTest>` **exits 0**, so had the row
   named the missing test alone it would have reported green forever. Command
   re-keyed to `TestCompileValidatesAttributes`.
2. **False-red, actual.** The D-68 docs row asserted
   `rg -q 'NOT instance-scoped'`. The documentation is correct and says exactly
   that thing — `background-job-authorization.md:169`, "is **not
   instance-scoped**" — but in lowercase, and **rg is case-sensitive by
   default**, so the assertion exited 1 against satisfied documentation. Command
   re-keyed to `rg -iq 'not instance-scoped'`, verified to exit 0 before being
   written here.

The row's other half, `scripts/check-docs-ia.sh`, exits 1 in a fresh worktree
because `site/dist/` has not been built — its four real invariants (INV-2, INV-3,
INV-5, INV-6) all pass, and CI's `Deploy Site` was `success` at `07ca74c46`. That
is an unbuilt-tree artifact, not a finding.
