## Sampling Rate

- **After every task commit:** `task test -- ./internal/access/... ./internal/world/...`
- **After every plan wave:** `task test` (full unit); additionally
  `task test:int -- ./test/integration/access/...` for any wave touching seeds or the compiler wiring
- **Before `/gsd-verify-work`:** full suite green; `task pr-prep` run **inline in the parent**
- **Max feedback latency:** ~60 seconds (quick lane)

> Per `CLAUDE.md`, verbose `task test|lint|build|test:int|test:cover` runs are delegated to the
> `local-check` agent; the FINAL `task pr-prep` before a push still runs inline in the parent.
