<objective>
Build the admin shell: a three-column container-query frame, a nav that is a projection of the
server's answer rather than a client registry, and the minimal planned-section state the six
deferred sections render.

Purpose: ADMIN-07 requires navigation filtered "by registry contract, not by template `{#if}`
blocks", and §10.1 names a mirrored client-side registry as Pitfall 7's hazard. D-101 keeps the
registry server-side so a future per-section grant needs no client change. Today the seed policy
is resource-**type** scoped, so the permitted set is all-or-nothing — which is exactly why a
client mirror would look correct and stay correct until the moment it did not.

Output: `AdminNav.svelte` rendering the awaited response, the `@container vp` frame with the
rail-merge treatment at 768–1023px, the planned-section route, and the two-class error split
that renders the ordinary not-found on a denial and one viewer-identical retry state on an
outage.
</objective>

**Specify the residue, because "exactly two classes" is not a classifier** (cross-AI review
R-36). `Unavailable`, `DeadlineExceeded` and a non-`ConnectError` transport throw are
`'infrastructure'`. **Everything else — `PermissionDenied`, `Unauthenticated`, `NotFound`,
`Internal`, `Unknown`, an unexpected `FailedPrecondition`, and any code added later — is
`'denial'`.** The default is the denial branch on purpose, and this is a **fail-safe** default,
not a fail-open one: the denial branch renders the ordinary not-found, which is the most
conservative thing this surface can show and is exactly what an unauthorised viewer sees. A
default of `'infrastructure'` would render a retry state for a genuine refusal, telling the
viewer that something exists here to retry. Write that reasoning into the function's doc
comment and pin it with a Vitest case per code, including one for a code the union does not
enumerate.

**`web/src/routes/(authed)/admin/+layout.ts`** — finalise the load:

  affordance is the existing app shell, not an admin-specific skeleton.
- **Denial-class** → `error(404)` so the ordinary root `+error.svelte` renders. Never

- **Infrastructure-class** → return a `loadFailed: true` flag; the layout renders one shared
  state with the copy `Couldn't load the admin portal. Try again.` plus a retry control. It is
  **identical for every viewer** and names no section and no permission.

  not-found, not an empty-nav state. Sketch 003's `No sections available.` nav copy is
  **declined** — it predates invisible-without-permission and is a third rendering of
  "nothing here".
