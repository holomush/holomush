<objective>
Author sections 12, 14 and 15 — the **Verification Integrity** rules (PORTAL-10), the
**Amendments and Divergences** table, and **Out of Scope** — and then apply the amendments to the
four live artifacts so the SPEC and its sources do not contradict each other.

Purpose: recording an amendment is not applying it. Downstream planners read `ROADMAP.md` and
`REQUIREMENTS.md` directly; a criterion that still says an owner can toggle field visibility will be
planned regardless of what a SPEC table says about it. The design-review learnings name exactly this
— an amendment row whose superseded string is still live in a sibling artifact — as a recurring
review failure.

Output: three complete SPEC sections and four artifacts brought into agreement with them.
