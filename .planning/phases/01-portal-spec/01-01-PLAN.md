## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous web visitor -> public profile read | fully untrusted; the tier floor is the only gate |
| guest session -> profile read | weakly authenticated; a guest must not reach player-floor attributes |
| downstream phase planner/executor -> this SPEC | the SPEC is the instruction source; a hole specified here ships as a hole in Phases 2-6 |
| game operator config (policies rows, source=admin) -> the tier floor | privileged write that changes what anonymous visitors can read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information disclosure | Section 8 tier-floor specification | high | mitigate | Specify absence-not-emptiness as the enforcement mechanism and DENY-on-infra-failure explicitly; a floor that resolves permit on lookup error is the fail-open shape research CONFLICT 4 rejected. |
| T-01-02 | Information disclosure | Section 8 profile reachability | high | mitigate | Specify a not-found-equivalent indistinguishable from a nonexistent character; a distinct "private" response leaks existence. |
| T-01-03 | Elevation of privilege | Section 8 configuration authority | medium | mitigate | Specify the floor as an ABAC policy family evaluated by the default-deny engine, never a settings-store value consumed by projection code, so the decision cannot escape the engine. |
| T-01-04 | Tampering | Section 13 invariant scope allocation | medium | mitigate | Task 1 checkpoint resolves the boundary fit before any id is written, so no invariant is filed against a scope whose boundary excludes it. |
| T-01-05 | Repudiation | Section 8 seeded default vs stated principle | medium | mitigate | Record the grid-parity divergence explicitly (D-14) so the more-open default reads as a decision with an owner, not an accident. |
| T-01-06 | Information disclosure | Section 7 always-public in-world description | high | mitigate | State D-08 normatively AND name PROFILE-11's audit as the only remaining gate, so Phase 2 cannot treat the audit as a formality. |
| T-01-07 | Denial of service | Section 8 read-time evaluation cost | low | accept | Read-time per-attribute evaluation costs one policy evaluation per attribute; the alternative (stamped rows) requires a backfill per configuration change, which migrations forbid. Cost accepted per D-12. |
</threat_model>
