<objective>
Ship the two format guards criterion 5 requires: D-13's `$$` ↔ `StatementBegin`/`StatementEnd`
pairing meta-test, and a static assertion that the `no-timestamptz` lint still scans the renamed
migration corpus.

Purpose: both defend against a *silent* failure. A future `$$` migration without the wrappers is
torn at semicolons by goose's line-based splitter; and a lint whose glob matches nothing exits 0
and reports clean. Neither is caught by running the thing — the pairing bug is caught by review
only, and the glob bug passes its own lint. Each therefore needs a check that is red against the
broken state and can be demonstrated so.

Output: `internal/store/migrations_format_test.go` and two additions to
`internal/store/lint_meta_test.go`, both running in the fast `task test` lane.
</objective>

  <behavior>
    `statementBlockViolations(name, body string) []string` returns one human-readable violation
    string per problem, empty when clean. Table-driven over synthetic bodies:
    - a body with `DO $$ ... END $$;` enclosed by `-- +goose StatementBegin` / `-- +goose StatementEnd`
      → no violations
    - the same body with the markers removed → one violation naming the line number
    - a body whose only dollar sign sequence is the bcrypt literal `'$2a$10$N9qo8uLOickgx2ZMRZoMye'`
      → no violations (the tag pattern requires an identifier start, so `$2a$` is not a tag)
    - a body with `-- +goose StatementBegin` and no matching `-- +goose StatementEnd` → one
      violation naming the unbalanced marker
    - a body with `-- +goose StatementEnd` before any `-- +goose StatementBegin` → one violation
    - an empty body → no violations
    Corpus-wide: applying the function to every file in `migrationsFS` yields zero violations, AND
    the number of files containing at least one dollar-quote tag is `>= 1` (non-vacuity — a scan
    that matches nothing must not read as clean).
    Demonstrated RED: run the corpus test against a temporarily unwrapped copy of one real
    migration body and observe it name that file and line.
  </behavior>
  <action>
    Create `internal/store/migrations_format_test.go` as `package store` with **no build tag** —
    that combination is load-bearing twice over: `package store` is what reaches the unexported
    `migrationsFS`, and the absence of `//go:build integration` is what makes `task test` (which
    does not compile integration files) actually run it, which is what D-13's "fails CI" means.
    Contrast `internal/store/migrations_test.go`, which IS integration-tagged and therefore
    invisible to the fast lane.

    Implement `statementBlockViolations(name, body string) []string` as a pure function over
    strings, so the table-driven unit test can drive it with synthetic bodies and produce a real RED
    without touching the corpus. Scan line by line, tracking whether the cursor is inside a
    `-- +goose StatementBegin` / `-- +goose StatementEnd` region; report a violation for any
    dollar-quote tag found outside a region, for an unclosed region at EOF, and for an
    `End` without a preceding `Begin`. The dollar-quote tag pattern MUST require an identifier
    start — `\$([A-Za-z_][A-Za-z0-9_]*)?\$` — so the bcrypt literal `$2a$10$...` is not treated as a
    tag. Every violation string names the file and the line number, so a failure is actionable
    without re-deriving it.

    Add the corpus test: `migrationsFS.ReadDir("migrations")` with `require.NoError` for the read,
    then `assert` per entry so one bad file does not hide the rest (the repo's require-for-
    preconditions / assert-for-the-check-under-test rule). Add the non-vacuity assertion in the same
    test: at least one file must contain a dollar-quote tag, or the whole check is scanning nothing.
    Do NOT assert the current census (9 files, 24 blocks) as a pass condition — record it in the
    SUMMARY as the observed baseline instead, so a legitimate new `$$` migration does not fail.

    Name both tests as ACE sentences, PascalCase, no underscores — e.g.
    `TestEveryDollarQuotedMigrationBodyIsWrappedInStatementBeginEnd` and
    `TestStatementBlockViolationsIgnoresBcryptDollarLiterals`. Do not copy
    `migrations_test.go:24`'s pre-ACE `TestMigration_000030_...` form.

    Demonstrate RED before declaring done: copy one real migration body into the table with its
