<objective>
Rewrite every live guidance surface that describes the migration format, and give operators the two
procedures the cutover deploy needs: D-16's pre-deploy rehearsal and D-18's one-window rollback.

Purpose: criterion 5 names `.claude/rules/database-migrations.md` explicitly, but the pairing claim
lives in four places — the rule, `CLAUDE.md`, the contributor guide, and the `new-migration` project
skill (which RESEARCH did not enumerate; it also documents `task migrate:create` and instructs
authors to wrap migrations in `BEGIN; ... COMMIT;`, which goose forbids inside a transactional
migration). A rule file that is correct while the skill an agent actually invokes is wrong is not
a rewrite. On the operations side, D-02 makes the cutover an unattended irreversible write, and
D-06 declines all verification — the rehearsal is the compensating control, and it only exists if
it is written down where an operator looks.

Output: four guidance surfaces rewritten, two operator docs corrected, the rehearsal and rollback
procedures written with an expiry, and the obsolete bootstrap script retired.
</objective>
