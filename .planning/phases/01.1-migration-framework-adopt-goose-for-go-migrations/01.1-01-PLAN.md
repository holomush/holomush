<objective>
Replace golang-migrate with `github.com/pressly/goose/v3` and convert the 44 migration pairs to
goose single-file format, in one atomic change, proven end-to-end on a fresh database.

Purpose: this is the tracer. The migration engine and the migration file format are structurally
coupled — goose cannot parse `.up.sql`/`.down.sql`, and golang-migrate cannot parse a merged
`-- +goose Up` file — so no intermediate state exists in which one has changed and the other has
not (`01.1-RESEARCH.md` §Shape of the Conversion Commit; the repo squash-merges, so `main` never
observes the intermediate state). Proving `holomush migrate up` end-to-end through the real
`store.Migrator` before adopt, interleaving, or docs work exists keeps an architectural dead-end to
one commit.

Output: a tree in which `task test` is green, a fresh database migrates to version 53 through
goose, the application schema is proven unchanged, and `force` is gone.
</objective>
