<objective>
Close the integration-tier breakage plan 01 knowingly left behind: three specs that read a
migration's own embedded SQL by `.up.sql`/`.down.sql` filename, and the absence of any assertion on
goose's bookkeeping end-state.

Purpose: the specs at `events_audit_partition_migration_integration_test.go:112` and
`migrations_sessions_location_index_integration_test.go:163,169` exist to execute the migration's
OWN SQL rather than a re-typed copy — a re-typed copy asserts the idempotency of the string the test
wrote, so deleting `IF NOT EXISTS` from the migration leaves the spec green. Under a merged goose
file, handing the whole file to `Exec` runs the **down** body too: the partition spec would drop the
partitioned parent it just probed, and the index spec would drop the index it just asserted. A
rename is not the fix; a one-direction accessor is.

Output: `store.MigrationSectionForTest(name, direction)`, its three callers migrated, and a spec
asserting criterion 1's bookkeeping end-state.
</objective>
