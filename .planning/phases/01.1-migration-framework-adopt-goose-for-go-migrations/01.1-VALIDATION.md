## Sampling Rate

- **After every task commit:** `task test -- ./internal/store/ ./cmd/holomush/ ./internal/bootstrap/`
- **After every plan wave:** `task test && task test:int` — **`test:int` is mandatory, not optional**, for
  every wave touching `store.Migrator` (`task test` does NOT compile `//go:build integration` files, so a
  refactor of shared types breaks silently otherwise)
- **Before `/gsd-verify-work`:** full suite green, then `task pr-prep` inline
- **Max feedback latency:** ~90s for the quick run
